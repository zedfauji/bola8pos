## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff keystrokes → `MoneyInput` value round-trip | The serialized `value` is read back and re-parsed as the user types; injecting formatting characters here corrupts the amount rather than the display. |
| app → agent model context | `posTools.ts` response fields are read by an LLM; a malformed or ambiguous money string can be reasoned over incorrectly. |
