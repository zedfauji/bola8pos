<objective>
Migrate the three surviving direct importers of the old `formatMoney`, plus the parallel ad-hoc PDF money formatter, onto `@shared/lib/format` — then delete the superseded helper so the TypeScript compiler proves no caller was missed.

Purpose: SC-2 and SC-4 for the locale-parameterized (receipt/PDF/print) surfaces, which are the ones where getting locale wrong is invisible until a customer holds the paper.
Output: 4 migrated files, 1 deleted export, 2 updated test files.

Migration shape, per D-07: because `options` is optional, an existing call site needs only its import path changed — no call rewriting — unless it wants `showSign`. That holds for `MoneyDisplay` (plan 01) and `ResourceIllustration` (task 2 here). The two locale-parameterized consumers in task 1 are the exception, since they move to `formatMoneyIn` and gain a first argument. Per D-05 this is done by hand throughout; ROADMAP SC-2's wording says "codemod", and D-05 explicitly overrides it — no `jscodeshift` or `ts-morph` is introduced anywhere in this phase.
</objective>
