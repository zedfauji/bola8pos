<objective>
Remove the still-reported dead declarations in the `shared/` and `features/` layers.

At planning time this batch held roughly 118 findings: about 109 under `src/shared/` (led by `supabase-contracts.ts`, `result.ts`, `test-utils.tsx`, `supabase.ts`, `mocks.ts`, `domain-helpers.ts`, and `config/constants.ts`), 7 scattered across `src/features/` hooks and dialogs, and 2 in `e2e/helpers/supabase.ts`.

The `shared/` layer is where a wrong deletion costs the most, because everything above it imports from it and because two of its files hold symbols that are consumed as **plain string literals rather than imported identifiers**. `rbac.ts` declares `STAFF_ACTIONS` and `canAccess(role, action: string)` casts the incoming string at runtime, so a permission name can be passed as `'void_order'` from a JSX prop with no import edge. `result.ts` declares `AppErrorCode`, and CLAUDE.md documents constructing errors as `{ code: 'YOUR_CODE' as AppErrorCode }`. In both cases knip's static analysis is structurally blind to the consumer, and deleting on its evidence alone silently removes a permission check or an error code.

Purpose: clear the shared and features dead declarations while treating string-keyed lookups as the known blind spot they are.
Output: per-finding dispositions and a green toolchain.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| role string -> permission check | `canAccess(role, action: string)` casts an untyped string at runtime; the permission set is reachable only as string literals from JSX props and hook arguments. |
| edge function response -> client error branch | `AppErrorCode` values cross the network as strings; a code with no TypeScript importer may still be produced by a deployed function. |
| external webhook payload -> constant match | `rappi-constants.ts` holds status and event strings compared against inbound third-party payloads. |
| shared utility -> every layer above | `src/shared/` is imported by entities, features, widgets, and pages; a wrong deletion here has the widest blast radius in the codebase. |
