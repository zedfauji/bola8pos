<objective>
Stand up the greenfield i18next infrastructure the whole phase builds on: install the three verified packages (behind a blocking package-legitimacy checkpoint), create the singleton i18next instance in the `shared` layer (NOT `app` — it is imported by shared/entities/features/widgets/pages, so FSD boundary rules force it to the lowest layer), scaffold all 10 namespace catalogs x 2 locales, wire init into the app bootstrap, and create the standalone `eslint.i18n.config.js` + `lint:i18n` script that every later sweep plan uses as its automated completeness gate.

Purpose: Everything downstream (schema, surfaces, sweeps, enforcement) depends on a working `t()`/`i18n.t()` and a way to prove a file is free of hardcoded strings. Establishing the singleton in `shared` (not `app`) here prevents an FSD boundary violation that would otherwise surface in every consumer plan (per D-04 the migration touches shared/ui, entities, features, widgets, pages — all must be able to import the imperative singleton).

Phase-wide catalog rule (applies to every plan that writes a catalog): the **es-MX value MUST equal the exact current on-screen literal, byte-for-byte, even when that literal is English** — es-MX is the default locale (D-02) and the Phase 34 visual baseline (`e2e/visual/45-visual-baseline.spec.ts`) was captured against today's mixed-language UI; changing es-MX copy would fail SC-4's zero-visual-regression contract. The **en-US value is the English rendering** (identical to es-MX where the current literal is already English; the English translation where the current literal is Spanish). Proper Spanish localization of existing strings is explicitly NOT in scope — this phase migrates the string *source*, not its *content*.

Output: `react-i18next` + `i18next` + `eslint-plugin-i18next` installed; `src/shared/lib/i18n/` singleton + 20 catalog JSON files; `main.tsx` wired; `eslint.i18n.config.js` + `npm run lint:i18n`; passing init unit test (SC-1). Implements D-02 (fallbackLng), seeds SC-3 enforcement tooling.
</objective>
