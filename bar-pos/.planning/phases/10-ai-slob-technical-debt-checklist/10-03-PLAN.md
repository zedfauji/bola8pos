Tier assignment rules — apply these exactly:

  - **Blocking:** eslint errors; `tsc` errors; failing unit tests; failing E2E tests; madge cycles whose file list spans more than one FSD layer (a genuine architecture violation against the `boundaries/elements` taxonomy); knip `unresolved` and `unlisted` findings (broken or missing imports that can break a build).

  - **Medium:** knip findings confined to `src/shared/ui/**` or `*.stories.tsx` — RESEARCH.md Pitfall 1 identifies these as knip's known false-positive surface for a component library, so they are listed for human triage rather than treated as confirmed debt; jscpd clones whose two sides live within the same FSD slice; madge cycles whose every file shares the same `src/<layer>/<slice>/` prefix, i.e. barrel-file indirection rather than a real logic cycle (RESEARCH.md Pitfall 2).
